# Worked examples

Run these from the repository root after installation. Each prints whether the fit was certified and retains failed searches in the result object. The examples illustrate operation; one simulated dataset is not a performance study.

| Command | Demonstrates |
|---|---|
| `python examples/quickstart.py` | Nonalternating types, curved hazards, unequal clusters, static covariate |
| `python examples/time_dependent.py` | Covariate updates within episodes; singleton and larger clusters |
| `python examples/alternating.py` | Alternating onset/end risk, off-risk washout, measured covariate, independent subjects |
| `python examples/from_csv.py` | The included synthetic CSV and explicit data preparation |
| `python examples/compare_sample_sizes.py --replicates 3` | A small joint-growth experiment, preserving every failure |

The first example uses 90 subjects in 30 independent clusters. Its fixed-seed fit has one zero clinic variance; this usefully illustrates why point estimation can succeed while an interior interval calculation is unavailable. The time-dependent example has 92 subjects in 40 clusters, including singleton clusters. The alternating example has 80 independent subjects. These are synthetic designs, not approximations formed by resampling the clinical data.

In the growth example, cluster counts, individual follow-up, and baseline bins increase together. A small default replicate count keeps the example runnable. Increase it for a serious numerical study and prespecify the design; the example does not reproduce or replace the manuscript's simulation results.

The CSV is generated by `simulate_demo(n_clusters=12, followup=16., seed=17)` and contains synthetic identifiers only. `examples/synthetic_truth.json` records the generating parameters. The generator is deterministic for the recorded NumPy environment; cross-version random-number/solver differences can change the final low-order digits.
